# Scanly

Scanly — приложение для iPhone и iPad, которое помогает сохранять расходы по бумажным и цифровым чекам. Оно распознаёт текст чека, подготавливает черновик расхода для проверки, хранит записи на устройстве и показывает сводки по категориям и месяцам. Приложение подходит для личного учёта расходов; исходники пока не включают сервер Scanly или учётную запись пользователя.

Интерфейс и строки приложения локализованы на английский, немецкий, испанский, французский, итальянский, нидерландский и польский языки.

## Возможности

- Сканирование чека встроенной камерой документов или импорт изображения через системный выбор фотографий.
- Распознавание текста на устройстве с помощью Apple Vision.
- Необязательное извлечение продавца, суммы, валюты, даты и категории из распознанного текста с помощью Anthropic API.
- Просмотр и редактирование распознанных данных и текста чека перед сохранением.
- Список расходов с валютой, датой и категорией; записи можно удалять.
- Сводка расходов по категориям за текущий месяц и график итогов за последние шесть месяцев. Для сводок выбирается одна валюта; пересчёта между валютами нет.
- Экспорт списка расходов в CSV или PDF через системное меню отправки.
- Бесплатный план с лимитом в пять сохранённых расходов и подписка Scanly Pro без этого лимита через RevenueCat.
- Экран настроек с состоянием подписки, восстановлением покупок и ссылками на политику конфиденциальности и условия использования.
- Первоначальное знакомство с приложением, которое можно пропустить.

## Как устроено приложение

После первого запуска показывается вводный экран. Затем приложение открывается на одной из четырёх вкладок:

1. **Сканирование** — снять чек или выбрать изображение. После OCR приложение предлагает черновик: пользователь проверяет и при необходимости исправляет данные, затем сохраняет расход.
2. **Расходы** — просматривать и удалять сохранённые записи, добавлять демонстрационную запись, экспортировать данные или перейти к предложению Pro.
3. **Аналитика** — смотреть расходы по категориям за текущий месяц и помесячные суммы за полгода.
4. **Настройки** — управлять подпиской и восстановлением покупок, открывать юридические ссылки; в Debug-сборке доступны диагностические элементы и QA-чек-лист.

Для бесплатного плана предусмотрено до пяти сохранений расходов, созданных через сканирование; счётчик лимита хранится в `UserDefaults`. Статус Pro проверяется через RevenueCat. Покупки требуют настроенных продуктов и Offering в RevenueCat.

## Технологии и структура

- **SwiftUI** — интерфейс, вводный экран и навигация по вкладкам.
- **Core Data** — хранение расходов; модель включает дату, сумму, валюту, продавца, категорию, распознанный текст и поле для изображения.
- **Vision и VisionKit** — распознавание текста и сканер документов; приложение использует первую страницу результата сканирования.
- **PhotosUI** — выбор изображения чека из медиатеки.
- **Charts** — графики аналитики.
- **RevenueCat** — загрузка предложений, покупка и восстановление подписок.
- **Anthropic Messages API** — дополнительная обработка OCR-текста, если передан ключ API.
- **Swift Package Manager** — подключение RevenueCat; зафиксированная версия пакета в `Package.resolved` — 5.68.0.

Исходники Swift сгруппированы в `Scanly/Core` (модель, хранение, сервисы и экспорт) и `Scanly/Features` (экраны сканирования, аналитики, оплаты, настроек и ввода). `Scanly/Localizable.xcstrings` содержит каталог переводов, а `Scanly/PrivacyInfo.xcprivacy` — декларацию privacy manifest приложения.

## Требования

- macOS и Xcode 15 или новее.
- iOS 16 или новее для устройства или симулятора.
- Для тестирования покупок — проект и продукты, настроенные в App Store Connect и RevenueCat.
- Для сборки на физическое устройство — выбранная в Xcode команда разработчика и действующие настройки подписи.

## Запуск и сборка

1. Откройте `Scanly.xcodeproj` в Xcode.
2. Выберите схему `Scanly` и симулятор iPhone/iPad либо подключённое устройство.
3. Дождитесь разрешения зависимости RevenueCat через Swift Package Manager.
4. Запустите приложение кнопкой **Run**. Для теста на устройстве настройте подпись в разделе Signing & Capabilities.

Сборка для симулятора из терминала:

```sh
xcodebuild -project Scanly.xcodeproj \
  -scheme Scanly \
  -sdk iphonesimulator \
  -configuration Debug \
  CODE_SIGNING_ALLOWED=NO \
  build
```

Для проверки покупок задайте `REVENUECAT_API_KEY` в Xcode: **Product → Scheme → Edit Scheme → Run → Arguments → Environment Variables**. В RevenueCat нужно настроить entitlement `pro` и текущее Offering с доступными пакетами. Без ключа приложение запускается, но покупки и восстановление подписок отключены.

Дополнительное заполнение полей чека включается переменной `ANTHROPIC_API_KEY` в том же разделе схемы запуска. Без неё приложение использует локальную обработку распознанного текста и оставляет поля доступными для ручной правки. Значения ключей не хранятся в репозитории. Не встраивайте Anthropic API-ключ в распространяемую сборку: клиентский ключ можно извлечь из приложения; для production-интеграции нужен защищённый серверный посредник.

## Разрешения и обработка данных

- **Камера** — используется системным сканером документов. Если сканер документов недоступен на устройстве, приложение не предлагает этот способ съёмки.
- **Фото** — изображение можно выбрать системным `PhotosPicker`. В проекте задано описание использования доступа к фототеке.
- **Чек и расходы** — распознанный текст и поля расхода сохраняются в локальном хранилище Core Data. При сохранении приложение не записывает исходное изображение чека в поле изображения. В исходниках не обнаружено синхронизации этих записей с сервером Scanly.
- **Необязательная AI-обработка** — если задан `ANTHROPIC_API_KEY`, приложение отправляет распознанный OCR-текст в Anthropic Messages API для извлечения полей. Само изображение этим запросом не отправляется. Условия обработки и хранения запроса определяются Anthropic.
- **Подписки** — при настроенном RevenueCat приложение обращается к RevenueCat для получения сведений о покупках, предложений и восстановления покупок. Privacy manifest указывает историю покупок как связанный с пользователем тип данных для функциональности приложения и декларирует отсутствие tracking.
- **Экспорт** — CSV/PDF-файл создаётся во временной папке устройства и передаётся через системное меню отправки; дальнейший выбор места или получателя делает пользователь.

В исходниках заданы ссылки на `https://scanly.app/privacy` и `https://scanly.app/terms`. Перед выпуском проверьте, что опубликованные документы и декларации конфиденциальности соответствуют фактической конфигурации сервисов и требованиям площадок.

## Известные ограничения проекта

- AI-разбор необязателен и сейчас вызывается приложением напрямую через Anthropic API; серверного прокси в репозитории нет.
- Работа подписок зависит от ключа RevenueCat, настроенного entitlement `pro` и опубликованного Offering.
- Для документа, отсканированного камерой, в черновик передаётся только первая страница.
- Аналитика не конвертирует валюты: суммы показываются отдельно для выбранного кода валюты.
- В репозитории нет отдельного XCTest target; `docs/RELEASE_CHECKLIST.md` содержит список ручных проверок перед выпуском.
- В каталоге App Icon находится конфигурация asset catalog без включённого изображения иконки; для выпуска её нужно добавить.

## Состав репозитория

- `Scanly/` — исходники приложения, модель Core Data, локализации, privacy manifest и ресурсы.
- `Scanly.xcodeproj/` — проект Xcode и общая фиксация зависимости Swift Package Manager.
- `docs/RELEASE_CHECKLIST.md` — список подготовки и ручной проверки релиза.

В репозитории нет пользовательских чеков или локальных настроек Xcode. Не добавляйте ключи API, сертификаты подписи, профили provisioning или пользовательские данные в коммиты.
